# MMDetection3D 框架完整学习文档

## 1. 项目概述

MMDetection3D 是基于 PyTorch 的开源 3D 目标检测工具箱，属于 [OpenMMLab](https://openmmlab.com/) 项目体系。

### 1.1 核心能力
- **多模态/单模态检测器**：支持纯激光雷达、纯相机、多模态融合三大类检测器
- **室内外场景覆盖**：KITTI、nuScenes、Waymo、ScanNet、SUNRGB-D、Lyft、S3DIS、SemanticKITTI
- **丰富模型库**：300+ 模型、90+ 论文实现
- **高性能**：训练效率领先（如 VoteNet: 358 samples/sec vs votenet 的 77）

### 1.2 技术依赖
| 依赖 | 说明 |
|------|------|
| PyTorch 1.8+ | 深度学习框架 |
| [MMEngine](https://github.com/open-mmlab/mmengine) | OpenMMLab 基础训练库，负责训练循环、钩子、配置等 |
| [MMCV](https://github.com/open-mmlab/mmcv) | 计算机视觉基础库，提供数据处理、通用工具等 |

## 3. 核心模块详解

### 3.1 注册表系统（Registry）

MMDetection3D 扩展了 MMEngine 的注册表，提供 17 个注册节点：

| 注册表名 | 用途 | 位置 |
|----------|------|------|
| `MODELS` | 神经网络模块 | `mmdet3d.models` |
| `DATASETS` | 数据集类 | `mmdet3d.datasets` |
| `TRANSFORMS` | 数据流水线变换 | `mmdet3d.datasets.transforms` |
| `TASK_UTILS` | anchor生成器、box编码器、assigner | `mmdet3d.models` |
| `METRICS` | 评估指标 | `mmdet3d.evaluation` |
| `HOOKS` | 训练钩子 | `mmdet3d.engine.hooks` |
| `INFERENCERS` | 推理类 | `mmdet3d.apis.inferencers` |
| `VISUALIZERS` | 可视化 | `mmdet3d.visualization` |

### 3.2 3D 检测器模型架构

典型 3D 检测器由以下组件构成：

```
点云输入
    ↓
[Voxel Encoder]      # 将点云转换为体素特征
    ↓                # 如: PillarFeatureNet (PointPillars), VoxelFeatureEncoder (VoxelNet)
[Middle Encoder]      # 处理体素特征
    ↓                # 如: PointPillarsScatter, SparseEncoder (SECOND)
[Backbone]           # 特征提取
    ↓                # 如: SECOND, PointNet++, DGCNN, MinkResNet
[Neck]               # 特征融合
    ↓                # 如: SECONDFPN, DLA_Neck
[Dense Head]         # 检测输出
    ↓                # 如: Anchor3DHead, CenterPointHead, FreeAnchor3DHead
[Detector]           # 完整检测流水线
```

#### 各层组件位置

| 组件类型 | 目录 | 示例 |
|----------|------|------|
| 体素编码器 | `models/voxel_encoders/` | PillarFeatureNet, VoxelFeatureEncoder |
| 中层编码器 | `models/middle_encoders/` | PointPillarsScatter, SparseEncoder, SparseUnet |
| 骨干网络 | `models/backbones/` | SECOND, PointNet++, DGCNN, MinkResNet |
| Neck | `models/necks/` | SECONDFPN, DLA_Neck |
| 检测头 | `models/dense_heads/` | Anchor3DHead, CenterPointHead, FreeAnchor3DHead |
| 检测器 | `models/detectors/` | VoxelNet, PointPillars, SECOND, PartA2, PV-RCNN |

### 3.3 数据集与评估

| 目录 | 内容 |
|------|------|
| `datasets/` | KITTI, nuScenes, ScanNet, Waymo 等数据集实现 |
| `datasets/transforms/` | 数据增强（RandomFlip3D, ObjectNoise, GlobalRotScaleTrans 等） |
| `evaluation/metrics/` | KittiMetric, NuScenesMetric 等评估指标 |
| `evaluation/functional/` | 底层评估函数（计算 AP、AOS 等） |

## 4. 配置系统

MMDetection3D 使用 MMEngine 的配置系统，支持模块化继承。

### 4.1 配置文件结构

```python
# configs/pointpillars/pointpillars_hv_secfpn_8xb6-160e_kitti-3d-3class.py
_base_ = [
    '../_base_/models/pointpillars_hv_secfpn_kitti.py',  # 模型基础
    '../_base_/datasets/kitti-3d-3class.py',             # 数据集基础
    '../_base_/schedules/cyclic-40e.py',                  # 训练调度基础
    '../_base_/default_runtime.py'                         # 运行时基础
]

# 配置主要 sections
model = dict(...)              # 模型架构
train_dataloader = dict(...)   # 训练数据加载器
val_dataloader = dict(...)     # 验证数据加载器
test_dataloader = dict(...)    # 测试数据加载器
train_cfg = dict(...)          # 训练循环配置
optim_wrapper = dict(...)      # 优化器配置
param_scheduler = dict(...)     # 学习率调度器配置
default_hooks = dict(...)       # 默认钩子配置
```

### 4.2 基础配置层级

| 层级 | 路径 | 内容 |
|------|------|------|
| Level 1 | `_base_/models/` | 基础模型结构 |
| Level 1 | `_base_/datasets/` | 数据集基础配置 |
| Level 1 | `_base_/schedules/` | 训练调度（lr衰减策略） |
| Level 1 | `_base_/default_runtime.py` | 钩子、日志等运行时配置 |
| Level 2 | `configs/[method]/` | 方法特定配置 |
| Level 3 | - | 数据集特定覆盖 |

## 5. 训练与推理流程

### 5.1 训练

```bash
python tools/train.py configs/pointpillars/pointpillars_hv_secfpn_8xb6-160e_kitti-3d-3class.py --work-dir work_dirs/pointpillars
```

**常用选项**：
| 选项 | 说明 |
|------|------|
| `--amp` | 启用自动混合精度 |
| `--sync_bn` | 转换为 SyncBatchNorm |
| `--resume` | 从 checkpoint 恢复训练 |
| `--cfg-options` | 覆盖配置值 |
| `--launcher` | 分布式训练启动器（pytorch/slurm/mpi） |

**训练流程**：
1. 通过 `Config.fromfile()` 加载配置
2. 可选替换 ceph 后端
3. 合并命令行选项到配置
4. 通过 `Runner.from_cfg(cfg)` 构建 runner
5. 调用 `runner.train()`

### 5.2 测试/推理

```bash
python tools/test.py configs/pointpillars/pointpillars_hv_secfpn_8xb6-160e_kitti-3d-3class.py checkpoint.pth --show --show-dir outputs
```

**流程**：加载配置和 checkpoint → 构建 runner → 调用 `runner.test()`

### 5.3 高层推理 API

```python
from mmdet3d.apis import LidarDet3DInferencer, init_model

# 使用 Inferencer 类（推荐）
inferencer = LidarDet3DInferencer(model='config.py', weights='checkpoint.pth')
result = inferencer(points='pointcloud.bin')

# 旧版 init_model 方式
model = init_model('config.py', 'checkpoint.pth', 'cuda:0')
result = inference_detector(model, point_cloud)
```

## 8. 学习路径推荐

### 阶段 1：入门
1. 阅读 `docs/en/get_started.md` 了解安装
2. 运行 `demo/` 中的演示脚本熟悉基本推理流程

### 阶段 2：理解配置系统
1. 仔细阅读 `docs/en/user_guides/config.md`
2. 研究 `configs/_base_/` 中的基础配置
3. 查看 `configs/pointpillars/` 中的具体示例

### 阶段 3：理解模型架构
1. 阅读 `mmdet3d/models/detectors/base.py` 了解检测器基类
2. 学习具体检测器实现（如 PointPillars, SECOND）
3. 阅读 `docs/en/advanced_guides/customize_models.md`

### 阶段 4：掌握训练流程
1. 阅读 `docs/en/user_guides/train_test.md`
2. 理解 `tools/train.py` 和 `tools/test.py`
3. 研究 `mmdet3d/engine/hooks/` 中的钩子实现

### 阶段 5：数据集定制
1. 阅读 `docs/en/user_guides/dataset_prepare.md`
2. 研究 `mmdet3d/datasets/` 中的数据集实现
3. 理解 `mmdet3d/datasets/transforms/` 中的数据增强

### 阶段 6：高级定制
- `docs/en/advanced_guides/customize_dataset.md` - 自定义数据集
- `docs/en/advanced_guides/customize_models.md` - 自定义模型
- `docs/en/advanced_guides/customize_runtime.md` - 自定义运行时
